## 这是什么

钨极在屏幕底部放一条**窗口级任务条**，每个打开的窗口单独占一张卡片——就像 Windows 任务栏那样——点一下直接切换，不需要三指手势，不需要 Mission Control，不需要多余的操作。

和纯 Windows 风格不同的是：只有一个窗口的应用以图标形式压缩显示，任务条不会被撑满。四个访达窗口、多个浏览器窗口的应用才展开成多张卡片。结果是：macOS Dock 的紧凑 + Windows 任务栏的窗口清晰，两者的优点，没有各自的问题。

## 主要功能

- **窗口级任务条**：一窗一卡，多窗口应用拆成多张卡片，点击切换 / 最小化。
- **原生标签智能合并**：Ghostty、访达这类「标签即窗口」的应用，切标签时卡片不乱跳、不分裂。
- **消息应用常驻 + 角标**：微信、飞书等消息应用有固定常驻入口，并镜像系统 Dock 的红圈未读角标。
- **应用抽屉**：不常用的应用收进右侧抽屉，保持任务条清爽；抽屉里还能固定常用应用当启动器。
- **拖拽整理**：拖动卡片排序；把卡片拖进抽屉收纳；从抽屉拖回任务条，落在你松手的精确位置。
- **菜单栏控制**：状态栏菜单里可以设置登录时启动、系统 Dock 显隐和钨极自己的唤醒时间。
- **边缘自动隐藏**：钨极可以自动隐藏；鼠标停在屏幕底边达到设定时间后唤醒，离开后约 `0.2s` 再隐藏。
- **磨砂玻璃质感**：原生级的毛玻璃材质，融入桌面。
- **多屏跟随**：鼠标在另一块屏幕底边停留后，任务条会自动切到那块屏幕。

## 系统要求

- macOS 12.0 (Monterey) 及以上
- Intel 与 Apple 芯片均可
- 首次运行需要授予**辅助功能**权限（用于读取和操作窗口，应用会引导你开启）

## 安装

### 方式一：下载安装包（推荐普通用户）

1. 从 [Releases](../../releases) 下载最新的 `.dmg`。
2. 打开后把 **Tungsten Edge** 拖进「应用程序」文件夹。
3. 从「应用程序」启动 Tungsten Edge，并按引导开启辅助功能权限。不要直接运行 DMG 里的临时副本。

### 方式二：Homebrew（技术用户）

```bash
brew tap moonbai-studio/tungsten-edge
brew trust moonbai-studio/tungsten-edge
brew install --cask tungsten-edge
```

> `brew trust` 这步是必须的——Homebrew 对所有第三方 tap 都要求手动确认信任，否则直接拒绝安装。

## 首次启动与辅助功能权限

从 v0.6.6 起，公开安装包使用 Developer ID 签名并经过 Apple 公证。把 App 移入「应用程序」后可正常双击启动，不再需要右键打开或「仍要打开」。

钨极需要辅助功能权限来读取和管理窗口。第一次运行时，应用会打开「系统设置 → 隐私与安全性 → 辅助功能」：

macOS 12 Monterey 中对应入口是「系统偏好设置 → 安全性与隐私 → 隐私 → 辅助功能」。

1. 找到 **Tungsten Edge**，打开右侧开关。
2. 授权成功后，引导窗口会自动关闭，任务条继续启动。
3. 若应用是从 DMG 或系统的 App Translocation 临时路径运行，引导会先要求移入「应用程序」并重新打开，避免给错误副本授权。

### 从 v0.6.5 或更早版本升级

旧版公开包使用临时签名。升级后，系统设置中的旧开关可能仍然亮着，但 macOS 实际没有把权限授予当前版本。v0.6.6 第一次迁移到正式签名时需要最后重新授权一次：

1. 退出所有 Tungsten Edge，卸载 DMG，并确认只保留 `/Applications/Tungsten Edge.app`。
2. 在「辅助功能」列表中选中旧 Tungsten Edge，用减号彻底删除；不要只关闭再打开旧开关。
3. 从「应用程序」重新启动 Tungsten Edge，再给新出现的条目开启权限。

若仍未生效，可在终端执行下面的针对性重置，然后重新启动并授权：

```bash
tccutil reset Accessibility com.caye.macosdockcc.v2
```

若干净重授权后依然无效，反馈时请附上实际启动路径、是否存在重复副本、macOS 版本、Mac 架构及最近的 `tccd` 日志；不要公开无关的私人路径。

完成这次身份迁移后，后续使用同一 Developer ID 的升级不会再反复丢失辅助功能授权。

## 状态栏菜单

钨极常驻在 macOS 菜单栏里。当前菜单包含：

- **登录时启动**：macOS 13 及以上可用。如果系统显示需要批准，请打开系统设置里的登录项并批准钨极。
- **隐藏/显示系统 Dock**：根据系统 Dock 的实际自动隐藏状态动态显示下一步动作。点击只改变显隐并重启 Dock，不会覆盖系统原有的唤醒延迟；右侧 `⌥⌘D` 是 macOS 自带快捷键。
- **隐藏/显示 Tungsten Edge 钨极**：在常驻和上一次的自动隐藏唤醒时间之间切换。下面的紧凑滑杆调整唤醒时间：`常驻`、`0.1s`–`3.0s` 或 `不唤醒`。状态菜单关闭时，全局快捷键 `⌥⌘E` 执行同一切换；注册失败时菜单不显示快捷键提示，但命令仍可点击。钨极运行期间会独占 `⌥⌘E`，因此会覆盖 Safari「开发 → 清空缓存」和 Finder「文件 → 推出所有磁盘」的快捷键；项目所有者接受这两个低频冲突，以换取容易记住的默认快捷键。
- **检查更新…**：手动检查 GitHub 上的最新正式版本；发现新版本后会打开对应 Release 页面，由你下载安装。

系统 Dock 设置需要非沙箱版本才能直接应用，因为 macOS 沙箱应用不能直接写系统 Dock 偏好，也不能重启 Dock。

## 推荐配置（让最小化动画对准底部）

如果你把系统原生程序坞放在屏幕**两侧或顶部**，最小化窗口时动画会朝原生坞的方向飞，和底部任务条的方向不一致。建议把原生程序坞移回**底部**并设为自动隐藏，最小化动画就会缩向底部、与钨极一致：

- 系统设置 → 桌面与程序坞 → 「位置」选**底部**、打开**自动隐藏**。

系统 Dock 自己的唤醒行为继续在系统设置里调整；钨极状态栏菜单只负责隐藏或显示它。
