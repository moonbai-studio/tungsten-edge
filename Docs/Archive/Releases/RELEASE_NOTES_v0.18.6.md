## New and improved

- The Tungsten Edge menu now uses four glass-style toggle buttons for Shelf, Trash, Name on Hover, and keeping maximized windows above the taskbar.
- Reorganized Settings → General, refined menu headings and separators, and improved Brazilian Portuguese text.
- Moved Check for Updates… from Settings → About to the Tungsten Edge menu in the menu bar; automatic update settings remain in Settings → About.

## Installing

**Already on 0.9.0 or later?** Do nothing — the update will find you, or use *Check for Updates…* in the Tungsten Edge menu in the menu bar. Your Accessibility permission carries over.

**New install:** grab the `.dmg` from the [official website](https://tungstenedge.app) and drag it into Applications, or:

```bash
brew install --cask tungsten-edge
```

Requires macOS 12 or newer. Universal — Apple silicon and Intel.

## 新增与改进

- 钨极菜单中的「中转站」「废纸篓」「悬停名称」和「最大化避让」改为四个玻璃按钮，可直接点击切换。

## 安装

**已经装了 0.9.0 或更新的版本？** 什么都不用做——更新会自己找上门，也可以在菜单栏的钨极菜单里点「检查更新…」。辅助功能授权不用重新给。

**新装：** 到[官网](https://tungstenedge.app)下 `.dmg` 拖进「应用程序」，或者：

```bash
brew install --cask tungsten-edge
```

需要 macOS 12 或更新版本。通用架构——Apple 芯片与 Intel 都可以。
